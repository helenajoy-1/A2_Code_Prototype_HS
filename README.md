# Ambient Noise Generator
Ambient Noise Generator uses sliders controlling audio files to create an ambient listening experience, allowing users to generate background sounds for relaxation, focus, or atmosphere.

## General Information
Ambient Noise Generator is a project designed to provide a customisable listening experience that supports relaxation, sleep, and concentration. Research suggests that ambient noise can help reduce sleep problems and support cognitive performance. However, finding the right combination of sounds can be highly situational and dependent on individual preferences.

The purpose of this project is to create an interactive tool that allows users to customise their ambient soundscape by selecting which sounds to include and adjusting their volume to suit their needs. Rather than repeatedly searching through YouTube videos or Spotify tracks to find suitable background noise, users can create their own sound environment in one place.

I undertook this project because of my own experience using ambient noise for both sleep and concentration. I often found myself switching between different recordings to find a sound that suited my needs, which could become distracting and interrupt my focus. By using code to address this real-world problem, I aim to develop a more flexible and personalised alternative that gives users greater control over their listening experience.

## Technologies
This project uses:
* Processing Java - version 4.5.6
* ControlP5 (Processing library) - version 2.2.6
* Sound (Processing library) - version 2.4.0 

## Setup
To run this project
1. Download and install Processing 4.5.6.
2. Clone or download this repository from GitHub.
3. Open Processing and load the main .pde sketch file.
4. Install the required libraries:
   * ControlP5
   * Sound
5. Ensure all associated audio files are in the processing files assets folder. 
6. Click Run in Processing to launch the ambient noise generator.
**Note: Both required libraries and all associated audio files must be available for the project to run correctly.**
